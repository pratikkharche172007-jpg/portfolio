# Pratik Kharche — Personal Portfolio

A responsive personal portfolio website for Pratik Kharche, a first-year B.Tech Computer Science and Artificial Intelligence student at Alard University, Pune.

## Built with
- HTML5
- CSS3 (Flexbox, Grid, responsive media queries)
- No JavaScript

## Project structure

```text
pratik-portfolio/
├── index.html
├── style.css
├── README.md
└── assets/
    └── pratik-kharche.webp
```

## Run locally
1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and the `assets` folder together.
3. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `pratik-portfolio`).
2. Upload all files and the `assets` folder, preserving the folder structure.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Notes
- The contact form uses a `mailto:` action. Submitting it opens the visitor's default email application; a server or form service is needed for direct website submissions.
- The LinkedIn link currently points to LinkedIn's homepage because a specific profile URL was not provided. Replace it with your profile URL when available.
- Skill bars are illustrative self-assessments, not certified proficiency ratings.
